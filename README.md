# Portal Escolar — Projeto de Interface Gráfica

## Objetivo

Este projeto foi criado para a Unidade Curricular **Fundamentos de Projeto de Interface Gráfica**.

O HTML das páginas já está pronto. O desafio do aluno é desenvolver o CSS e melhorar a experiência visual e a usabilidade do portal.

## Páginas

- `index.html` — Página inicial
- `aluno.html` — Área do aluno
- `professor.html` — Área do professor
- `administrativo.html` — Área administrativa
- `contato.html` — Página de contato

## Desafio

O aluno deverá:

1. Criar uma identidade visual.
2. Escolher cores e tipografia.
3. Organizar o layout.
4. Trabalhar hierarquia visual.
5. Estilizar cards e botões.
6. Utilizar Flexbox e/ou CSS Grid.
7. Criar um menu consistente entre as páginas.
8. Desenvolver uma versão responsiva.
9. Manter consistência visual em todas as páginas.
10. Melhorar a experiência do usuário.

## Regra sugerida

Na primeira etapa, **não alterar o HTML**. O objetivo é resolver os problemas de interface utilizando CSS.

Depois da avaliação inicial, o professor pode liberar alterações no HTML.
